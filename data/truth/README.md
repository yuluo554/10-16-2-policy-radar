# data/truth/：真值台账（只存输入与期望）

**核心纪律（K11）：本目录只存"输入与期望"，禁 `observed_*` 一类字段。**

判别口诀：**"我的基准，是在'跑被测对象'还是在'比对两份预先算好的答案'？"**
冻结"观测"会让基准退化成后者——引擎整个坏掉也照样全绿。观测由基准运行时**实算**。

| 文件 | 产出里程碑 | 内容 |
|---|---|---|
| `diff-truth.json` | M1 | 新增判定真值：`{input: {snapshot_a, snapshot_b}, expect: {new_ids, dup_ids, ...}}` |
| `pcode-truth.json` | M1 | 文号解析真值：`{pcode, expect: {agency_code, year, serial, status}}` |
| `subscribe-truth.json` | M1 | 订阅命中真值：`{item_id, expect: [{keyword, field, offset}]}` |
| `manifest.json` | M1 | 覆盖声明（**总数/采样数双登记**）+ 验收门槛（**随数据下发，代码零默认值**） |
| `README.md` | M1 | 真值语义一次定清（主期望 `expect` + 隐含结论 `also_expect`；对账语义单一实现源） |

## 覆盖声明要"总数/采样数"双登记

只写分子（"各有覆盖件"）就是假覆盖——manifest 须逐形态登记
**"规则包总数 / 真值库采样数 / 采样清单"**，并显式声明"抽样覆盖、非穷举"。

## 反向样例必须有

"该命中"的样例只证明引擎会命中；**"这条不该命中"的样例**才能证明适用域写对了。
文号真值必须含：`国令第847号`（不该解析出年份）、空 `pcode`（不该解析出代字）。

## 三件齐备（"冻结"名不副实的三问）

1. **入库件在不在**（`git ls-files` 查）；
2. **有没有位级守门**（生成器 `--check` 再生成逐字节一致）；
3. **有没有真调用方**（`grep` 得到调用方，且**用户敲的那条命令**真读它——不是只在测试里被读）。
