# data/snapshots/：预置快照对（字节冻结 fixtures）

本目录存放**真值基准用的预置快照对**——旧快照 A + 新快照 B，B 相对 A 的新条目即
"应判为新增"的真值，A∩B 条目即"应判为重复"的真值。

| 文件 | 产出里程碑 | 说明 |
|---|---|---|
| `pair-A.json` | M1 | 旧快照 |
| `pair-B.json` | M1 | 新快照 |
| `manifest.json` | M1 | 快照元信息 + 逐份 sha256 + 门槛（验收门槛随数据下发，代码零默认值） |

**字节冻结纪律**：
- 本目录是**生成器产物**（`tools/gen_snapshot_pairs.py`），**禁手改**；
- 改体例/生成器 → 用固定 seed 命令重新生成整目录提交，配"再生成位级一致"守门（**两层**：
  ① 冻结产物自身形态正确；② 重跑生成器到临时目录 → 与冻结产物逐字节比对）；
- `.gitattributes` 已标 `-text`（防克隆时 EOL 归一化改写字节 → sha256 失配）；
- 验证手段 = 克隆/检出后比对快照实际 sha256 与 manifest 登记值（`git status` 看不出来）。

M0 状态：目录已建，**文件为 M1 产出**。

**注意**：本目录是**基准数据**，不是运行时快照目录。运行时快照写入 `.gitignore` 覆盖的
`snapshots/`（仓库根）——真值基准用的预置快照对才入版本管理。
