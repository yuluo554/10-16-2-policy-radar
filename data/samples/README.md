# data/samples/：真实 API 响应样本（离线回归用，字节冻结）

本目录存放**真实抓取到的**中国政府网搜索 API 响应样本，供**离线回归**使用
（基准与测试绝不打真站点——真站点不可复现，且会触发对方风控）。

| 文件 | 产出里程碑 | 说明 |
|---|---|---|
| `gwy-p1-n5.json` | M1 | 国务院频道 `t=zhengcelibrary_gwy&q=&p=1&n=5&sort=pubtime&sortType=1` 真实响应 |
| `bm-p1-n5.json` | M1 | 部委频道 `t=zhengcelibrary_bm`（其余同上）真实响应 |
| `README.md` | M1 | 逐份登记：抓取日期 + 完整 URL + HTTP 状态 + sha256 |

**字节冻结纪律**：`.gitattributes` 标 `-text`（防克隆时 EOL 归一化改写字节 → sha256 失配）。
**验证手段** = 克隆/检出后比对样本实际 sha256 与登记值（`git status` 看不出来）。

**只存元数据**：样本是 API 返回的元数据响应，**不含政策正文**（边界 2：不做全文下载归档）。

**不写漂移硬数字**：样本里的 `totalCount` 是**冻结的历史快照**（记录那一刻的返回值），
允许存在；但**代码与测试断言不得内嵌该数**（M0 实测：`bm` 已由 12801 漂到 12803）。

M0 状态：目录已建，**文件为 M1 产出**。
