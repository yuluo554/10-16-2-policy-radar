# data/config/：规则数据

本目录存放**规则数据**（生成器产物或人工冻结），供解析层与订阅层消费。

**单一来源纪律**（K7 / K8）：同一份口径只准有一处定义——解析层与订阅层不得各写一份。

| 文件 | 产出里程碑 | 说明 |
|---|---|---|
| `org-aliases.json` | M1 | 部门别名表。只登记**实测出现过的**部门名（含"办公厅/办公室/综合司"后缀变体）与其规范名；未出现的不编造。匹配**最长优先** |
| `subscribe.json` | M1 | 订阅配置样例（含多关键词、排除词、**重复词**三类边界样本） |
| `normalize.json` | M1 | 全半角/异体字归一表（订阅匹配前归一，防 `〔`/`(` 类差异漏命中） |

三份都由 `tools/gen_pcode_cases.py`（别名表）与 `tools/gen_subscribe_cases.py`
（订阅 + 归一表）生成；`--check` 位级守门。

---

## 一、`org-aliases.json`（K7 部门别名表）

- **形态**：`{原始名: 规范名}`；另有 `canonical_orgs` 汇总规范名集合。
- **匹配规则**：`match_rule = longest_first`——**最长优先**。
  判别口诀：**"短串会不会吃掉长串前缀？"** 已知表里有 `住房城乡建设部` 与
  `住房城乡建设部办公厅` 时，短串优先会把后者读成前者，值静默错位。
- **未命中处置**：`unmatched_policy = keep_raw_and_flag_alias_missing`——
  认不出的部门**原样保留 + 标 `alias_missing`**，**不猜**。
- **实测规模**：39 条原始名 → 38 个规范名（唯一真变体对是
  `住房城乡建设部` → `住房和城乡建设部`，含其"办公厅"后缀形态）。
- **拆分前提**：`puborg` 是**空白分隔多部门**，且实测分隔符**含 U+2002 EN SPACE**
  并会与 U+0020 **混用**（M1 实测 E5）→ 归一前必须按 `\s` 类空白拆分，
  **不能只按 `' '`**，否则多部门串会变成单个不可识别 token。

## 二、`subscribe.json`（订阅配置样例）

- **不预置业务热词**（决策 P4 按推荐默认执行）：关键词全部取自观测池真实文本。
- 含三类边界：**多关键词**、**排除词**、**重复词**（`"规划"` 出现两次，
  用于验证"按归一后关键词去重、保持配置顺序"）。
- `field_priority = ["title", "summary"]`：命中字段优先序（单一来源）。
- `exclude_policy = drop_item_entirely`：exclude 命中**整条剔除**，不是"不标注"。

## 三、`normalize.json`（K8 归一表）

- **每条映射都是单字符 → 单字符**（`apply_to = both_keyword_and_text`）。
  这不是凑巧，是**刻意的设计约束**：长度保持使"命中位置 `offset`"在归一前后**同值**，
  因而 `offset` 语义唯一、可审计——否则归一化会移位，真值里的 offset 就成了
  "哪一份文本的下标"的糊涂账。
- 每条都有**实测依据**（不是凭空补的通用表）：
  | 映射 | 实测依据 |
  |---|---|
  | `“` `”` → `"` | 正文实测用全角弯引号（如 `“十五五”`），用户常按 ASCII 引号搜 |
  | `﹝` `﹞` → `〔` `〕` | **M1 实测 E6**：六角括号存在全角变体（U+FE5D/FE5E，与 U+3014/3015 不同码位） |
  | `\u3000` `\u2002` `\u00a0` → ` ` | **M1 实测 E5**：实测空白出现 U+2002 EN SPACE |
  | `（` `）` → `(` `)` | 全角括号，用户可能按半角输入 |
  | `‘` `’` → `'` | 全角单引号 |
