# data/config/：规则数据

本目录存放**规则数据**（生成器产物或人工冻结），供解析层与订阅层消费。

**单一来源纪律**（K7 / K8）：同一份口径只准有一处定义——解析层与订阅层不得各写一份。

| 文件 | 产出里程碑 | 说明 |
|---|---|---|
| `org-aliases.json` | M1 | 部门别名表。只登记**实测出现过的**部门名（含"办公厅"后缀变体）与其规范名；未出现的不编造。最长优先匹配 |
| `subscribe.json` | M1 | 订阅配置样例（含多关键词、排除词、重复词三类边界样本） |
| `normalize.json` | M1 | 全半角/异体字归一表（订阅匹配前归一，防 `〔`/`(` 类差异漏命中） |

M0 状态：目录已建（selftest 据此判定数据根完整性），**文件为 M1 产出**。

修改纪律：规则数据是**冻结产物**，禁手改；改需求走生成器整目录重生成，配"再生成逐字节一致"守门。
