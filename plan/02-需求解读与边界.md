## 三、边界与非目标（首期，超出即扩展项）

题面第六节的四条"不做/不承诺"，在实现层落成以下硬边界：

1. **不做政策解读/咨询**：只输出"新发变更提醒"，日报不含任何解读观点、影响分析、合规建议。日报文案模板里不得出现"建议/应当关注"类判断语句。
2. **不做全文下载归档**：快照只存 `title/pcode/pubtimeStr/puborg/url/summary/index/id` 等元数据字段；不抓 `url` 指向的正文，不落全文、不建全文索引。
3. **不承诺覆盖所有发文渠道**：只接两个频道（`gwy` / `bm`）。地方库、部委站点直抓一律列扩展项，README 不得暗示已覆盖。
4. **隐私红线**：纯本地运行，无遥测、无账号、无上传；`fetch` 只对 `sousuo.www.gov.cn` 一个域名发请求，且只发只读 GET。**不引任何第三方网络/分析 SDK**。

补充的工程边界（由 skill 纪律推导，非题面要求）：

5. **无 LLM**：`pcode` 是结构化字段，全链路确定性规则即可，不接任何大模型 API（决策 D6）。省下的精力投数据核对与基准。
6. **不依赖日期参数做增量**：`mintime/maxtime` 实测未生效（决策 D3），增量只能走快照 diff。
7. **抓取目标 URL 以 API 返回 `url` 字段为准**：gov.cn 旧路径大面积 404（决策 D2），不得自行拼路径。
8. **首期交付形态 = 源码包 + 本地 CLI**：不做 exe 打包（题面形态为"纯本地 Python CLI"，无 GUI/Web 需求）；扩展项触发时才评估。
